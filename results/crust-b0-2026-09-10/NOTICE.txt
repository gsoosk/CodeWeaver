This package records generated Rust translations of four C projects from
CRUST-bench, using interface skeletons and evaluation tests from that benchmark.

CRUST-bench: https://github.com/anirudhkhatry/CRUST-bench
The C projects are independent open-source works; see each project's own upstream
repository for its license. Only their `src/` trees were used as translation input,
and none of that source is redistributed here — this package contains generated
Rust, evaluation metadata and audits.

The held-out tests under metadata/<subject>/oracle-master/ are CRUST-bench's, kept
so the frozen translations can be re-scored. They were generated by an LLM from the
C sources against stub interfaces; they are NOT human-verified, unlike the
AlphaTrans oracle used elsewhere in this repository. Scores here are correspondingly
weaker evidence.

CRUST-bench ships no reference Rust implementation (98% of interface bodies are
`unimplemented!()`), so there is no gold translation against which a failing test
could be shown to be the test's fault. No exclusions were applied on that basis.

The repair arms are modeled on the compiler-guided and test-guided repair loops
described by CRUST-bench. This is an adaptation to a different evaluation protocol —
our oracle is held out from every generation arm, theirs is not — and these numbers
are not comparable to theirs.

Generation used a GitHub Copilot subscription reached through a separately
authenticated, user-run instance of the unofficial ericc-ch/copilot-api proxy on
loopback. That proxy is not affiliated with or supported by GitHub. No proxy code,
credentials or raw request/response streams are included here.

Generated outputs and benchmark observations are not upstream releases and are not
endorsed by the upstream projects. Known failures remain: three of four subjects do
not compile in the per-file arm, and one does not compile in any arm.
