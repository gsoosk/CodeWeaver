Re-scoring the frozen repair outputs
====================================

Use Linux with Python 3.12.3, pytest 9.1.1 and the AlphaTrans test dependencies.
Activate the benchmark environment if available:

  source "$HOME/cwenv/bin/activate"

Use the AlphaTrans dataset at commit c1cabf93d41a153de207d6b098e1da7bbd79abab.
The wrapper checks the dataset revision, oracle fixture manifest, bundled oracle
script hash and package manifest before running pytest.

From the CodeWeaver repository root:

  bash results/alphatrans-b0-repair-2026-09-09/reproduction/score.sh commons-cli build "$HOME/AlphaTrans"
  bash results/alphatrans-b0-repair-2026-09-09/reproduction/score.sh commons-csv build "$HOME/AlphaTrans"
  bash results/alphatrans-b0-repair-2026-09-09/reproduction/score.sh commons-fileupload build "$HOME/AlphaTrans"
  bash results/alphatrans-b0-repair-2026-09-09/reproduction/score.sh commons-validator build "$HOME/AlphaTrans"

Replace build with test for the test-guided arm.

The two arms are NOT comparable to each other. build is test-blind; test read the
oracle's failure output. See report/summary.txt before tabulating anything.

Every command returns nonzero: all retained outputs have failures, and
commons-csv additionally produces one collection error in both arms, so its
counts are not a pass rate. Run the commands individually, not chained with &&.

commons-cli and commons-fileupload consumed zero API calls in the build arm.
Their build-arm trees are byte-identical to the source B0 per-file artifact in
results/alphatrans-b0-api-2026-09-09, and re-scoring reproduces those same
numbers. That is the recorded outcome, not a copy error.

The wrapper uses the bundled public oracle script in a fresh temporary subject
tree. No pipeline/skips.json is present, so no repair-budget deferrals apply.
The fixed golden-baseline exclusions are preserved: one CurrencyValidator test
for commons-validator. Suite self-skips are reported separately.

This reproduces scoring of frozen output, not repair. No API access, proxy, or
model calls are required.

To re-run the repair itself, see experiments/baselines/campaigns/README.md. It
requires model access and will not reproduce these bytes exactly: the model is
nondeterministic and these runs were N=1.

Recorded scoring environment: LANG=C.UTF-8; LC_ALL and TZ unset.
Generated Python bytes are unchanged. Machine paths in textual evidence are
normalized and original hashes are retained in
metadata/publication-provenance.json.
